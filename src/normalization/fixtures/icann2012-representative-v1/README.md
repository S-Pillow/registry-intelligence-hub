# ICANN 2012 representative fixture bundle (v1)

**Not a full 2012 round export.** This bundle is a deliberately small, hand-authored slice used to exercise the offline normalization foundation:

- Conflicting applicant legal names across two synthetic sources
- A missing contention-set reference
- Redirect provenance on a raw snapshot ref
- IDN U-label / A-label pairing
- A multi-application contention set
- Conservative organization resolution (candidates only)
- Immutable override operations in `overrides.json`

Official totals from the 13 Jun 2012 Reveal Day overview (1,930 applications, etc.) are **not** reproduced here.
